# Found 搜索修复 v2：范围与来源审查

授权：2026-09-29 用户要求以 B0 V5、B1 V4 为起点修改 Hold、制动、搜索失效恢复及 Windows 手动实验接口。完整实验由用户启动；本次不训练、不加载检查点、不运行20场景评估。

## 实现边界

- 新算法只在 `chapter3_bser/experiments/safe_search_v2`，通过原有构造钩子和导航目标接口组装。R0直接返回原有B0 V5 / B1 V4类。
- V0–V5算法文件、共享core、原始控制律、动力学、奖励、观测28D、动作3D、网络和124D critic均不修改。
- H：Hold参考点在进入时固定；位置偏差可产生恢复力。新公开障碍使保持点或返回线段失效时重新设点并计数，不穿过已知障碍构造退路。
- D：仅收紧搜索者转弯跟踪阈值；在公开地图上检查一次候选运动后接制动的有限时域轨迹。速度意图通过原有导航点表达，残差仍为零。Hold增加速度反馈，固定参考点与实际命令点分别记录。
- 预测使用环境固定车辆常数及公开位置、速度。扰动来自上一步观测速度与标称速度之差；不访问真实障碍、隐藏目标或真实流场函数，不推进/恢复模拟器，不消耗随机数。
- 预测20步，检查名义扰动及六个轴向扰动样本，不是安全证明。所有前进指令被拒绝时使用制动，单独记录仍不安全的预测，不能声称已避碰。
- R：按智能体分别恢复，使用原有候选生成和B0/B1评分器；无效起点提前返回。独立10步重试，强制刷新不重置重试时钟。处理无分配、路径失效、路径走完和20步低位移。恢复前刷新权威图，使查询具有当前位置端点。
- 原子分配内部实现不改；单智能体恢复保留其他搜索者和执行者的分配，提交前检查该不变量。原有普通规划仍可发生。
- Found后新增Hold、制动、恢复退出。执行者跟踪阈值、待命策略和执行逻辑不作新修改；历史SafeSearch的发现后委托保留。

## 来源演进

原 `safe_search_v1_evolution.json` 及全部历史manifest保持原字节。唯一已有生产文件改动是v1 `provenance.py`的后继来源分派钩子；原来对每个历史profile、27条迁移记录、历史before/after绑定的检查仍完整执行。

新 `safe_search_v2_evolution.json` 声明该钩子及所有新增Python文件的精确before/after哈希。禁止其他旧文件变化、禁止任意目录豁免，全部profile均检查。来源验证返回完整当前库存及后继manifest哈希；运行中来源或输入变化即失败。

既有来源测试的临时副本携带新增manifest和审查文档；跨平台测试准备后继profile，继续验证混合profile拒绝、文件增加/删除/修改拒绝及历史manifest冻结。新增测试覆盖后继manifest的scope、before绑定、父manifest及未使用profile损坏。

固定原20开发场景、原始索引、seed=12729+原始索引、400步真实终止回合。默认只校验并打印计划；`--execute`启动。两基线均含原版R0；五组共200回合，R0/R4配对为80回合。

每回合独立进程，不训练、零残差。完整回合及发现后结果保留；Found、发现前碰撞、带失败惩罚的发现时间为主指标。程序失败、中断和缺失回合不算超时或物理失败，未完成组不发布完整Found率。

输出仅在仓库runs下新建。续跑要求相同来源、配置、场景、参数和输入路径，已完成行及轨迹逐项验证，未完成任务另建attempt，不覆盖旧轨迹。3090结果和runs仍由Git忽略。

## 风险与验证范围

固定Hold仍可能有非零稳态误差；新障碍覆盖保持点时需要重新设点。预测过于保守可能增加Hold并损失覆盖；逐智能体恢复可能改变联合分配效果。必须由固定配对实验判断效果，不能根据单元测试宣布Found提升。

本地验证限于机制、原SafeSearch任务回归、来源完整性、观测和路径跟踪契约、短步数真实接口，不自动触发训练、正式评估、HGR对比或剩余80场景。
