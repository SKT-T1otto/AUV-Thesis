## 已实现的修复

新增 `chapter3_bser/experiments/safe_search_v1/`，显式提供五个实验臂：V0 关闭、V1 规划状态一致性、V2 一致性加失败恢复、V3 路径安全、V4 全部开启。

- **连续位置与规划图一致性**：实际规划机会前识别陈旧起点端点，完整刷新公开快照，同一物理步最多一次；后续分配和 guidance 使用该状态。不使用近邻吸附伪造可达性。
- **失败处理**：区分失败退避与成功重规划冷却，普通收益事件保留原冷却；无当前连接的搜索者在候选枚举前短路。初始没有分配的搜索者也进入恢复流程，成功恢复后清除 pending。B1 的独立局部分配分支补上新增搜索者的合并，保留未受影响搜索者和执行者。
- **公开几何检查**：已知占据体素采用闭线段相交检查，包含面、棱、角接触；使用场景已有的 0.4 余量。过滤原图危险节点、边及连接段，重建连通标签，仍使用原成本和原查询算法。未知区域继续视为未知，不调用障碍真值。
- **失效路线执行**：初始化首次 guidance 前即接入，每步检查最新公开几何与剩余路线。优先尝试可验证路线；失败时将跟踪点设为当前位置，由原先验控制器制动。语义目标保持不变，不清零实际速度或位置。Found 后停用搜索附加处理，恢复原执行流程。
- **实验输出**：保留原 manifest 索引和 `12729 + 原索引` 创新种子；记录来源、输入哈希、实际查询、轨迹、停滞和 hold。非终止前缀明确为 `budget_cutoff`。

审查中另外修复了失败状态导致连续强制刷新、普通事件冷却被误改、同目标新路线被旧缓存覆盖、以及初始缺失分配无法恢复四类边界问题，均有回归测试。

仅三个旧文件增加默认等价的装配 hook：`hgr/runtime.py`、`online/allocator.py` 和 `tools/ch3_baselines/basic_search_prior.py`。将默认 hook 内联后，其 AST 与修改前 `44c86cd` 一致。没有改动 `core`、28D/3D/124D、奖励、任务规则或动力学。B0/B1 残差动作和物理残差始终为零；执行者仍使用原待命机制。
