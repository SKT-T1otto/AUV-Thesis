## 原 BSER 的处理

停用的是未来主线的联合响应加权搜索分配。保留 `chapter3_bser` 目录名、事件控制器、候选生成、路径服务和共享执行模块，D2 仍依赖这些基础设施。旧 B1、D/F 实验代码与原配置保留用于追溯；不删除旧结果、不把旧实验改名为 D2。

新的 `planner_protocol=d2_v1` 控制规划装配。缺少该字段的历史配置继续保留旧行为。当前 B2/B3 统一入口拒绝旧规划配置或旧权重冒充 D2。B0/B1 评估入口继续使用历史参考配置，不参与新主线默认训练。
