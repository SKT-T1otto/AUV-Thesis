# 地图时空路线影子诊断：有机制差异，收益尚不稳定

日期：2026-10-17。结论：**暂缓开发/集成完整 BA-STPR 分支，先验证采样稳定性和运动预测假设。** 本轮确认同终点存在多条可行路线，四种评分会改变选择，直接连乘时间边际也会严重高估模型内累计发现概率；但没有建立相关性评分相对静态评分的稳定收益。

没有训练、checkpoint 加载、Actor 前向或优化器更新。影子路线安装次数为零；没有执行正式或完整回合评估。原有 396 个源码/配置文件的字节哈希与本轮开始时一致，已有用户修改保留。源码、配置、输入和快照身份见同目录 JSON。

## 诊断规模与基线保持

- 固定开发场景索引 0、10、40、63、78、97；每场最多 30 步，采集 0/10/30 步公开快照。
- 实际共 164 个物理步、17 个快照。场景 40 第 14 步终止，仅取 0/10 步，不补场景、不补其 30 步快照。
- 51 个潜在 agent 案例中有 50 个有效多路线池，共 197 条通过预测几何筛选的路线。场景 78 第 30 步 agent 0 为 `invalid_start`，保留失败记录；该快照不参与完整三 Searcher 团队比较。
- 完整团队比较为 16 个快照、6 个场景，每快照最多 64 个固定终点路线组合。
- 17/17 个公开快照的位置和速度与历史 D2/F0 对应状态逐项精确一致。该检查验证这些状态点的公开运动学一致性，不是整回合或全部环境状态等价证明。
- 没有运行物理分支来比较影子路线。所有后续收益都是离线条件模型下的估计。

## 四组结果

四组共用相同路线池、Searcher 预测、硬 swept detector、12 秒时域和目标假设。选路与复核分别使用独立的 384 条目标轨迹。下表都以独立复核样本上的 **correlated-first 折扣收益** 评价各组已经选定的组合，按场景等权，避免用不同评分量纲直接比较。

| 选路评分 | 独立复核折扣首次发现收益 | 模型内 H 步发现概率 | 与 correlated-first 选择不同的团队快照 |
|---|---:|---:|---:|
| 静态匹配 detector 覆盖 | 0.223431 | 0.268446 | 16/16 |
| 静态覆盖 × 到达时间折扣 | 0.220765 | 0.263527 | 13/16 |
| 时变边际＋时间独立近似 | 0.220281 | 0.260127 | 12/16 |
| 保留轨迹相关性的首次发现 | 0.228526 | 0.270833 | — |

相关性评分相对静态评分的折扣收益差为 **+0.005095**，相对幅度约 +2.28%；模型内未折扣发现概率仅差 **+0.002387**（约 0.239 个百分点）。这些都不是环境 Found 提升。

逐 agent 换路比例分别为 23/50、22/50、11/50；团队组合只要任一 agent 改变就算变化，因此 16/16 团队变化不能解释为每个 agent 都改变，也不能当作有效性指标。

## 时间边际连乘的主要问题已被观察到

在 time-marginal 所选组合上，独立复核样本的平均累计发现概率：

- 边际独立连乘估计：**0.949844**。
- 对同一批轨迹只计最早发现：**0.264323**。

差异来自同一目标的跨时刻事件相关性，未引入 detector、地图、候选池或样本差异。它证明此处不能把未条件化 q_k 直接当作首次发现 hazard。这个结果支持采用相关性保留的概率计算，但不证明换路线后会增加真实发现率，也不等于该计算本身具有新颖性。

## 不能忽略的稳定性反证

相对静态评分，16 个团队快照中复核差值为正 11 个、为负 5 个；只有 **1/16** 的配对粒子 bootstrap 区间完全大于零。粒子区间反映 Monte Carlo 误差，不代表环境泛化误差。

按场景平均后的差值如下：

| 场景 | correlated-first − static |
|---|---:|
| 0 | +0.006876 |
| 10 | +0.020071 |
| 40 | +0.018804 |
| 63 | −0.008427 |
| 78 | −0.006827 |
| 97 | +0.000073 |

六场景的描述性 cluster bootstrap 区间为 **[−0.003660, +0.014328]**，跨零。场景数量小、开发集已反复使用，此区间不是正式确认实验结论。

保留原事前门槛：机会数量充足、换组合比例足够、按场景均值 +0.005095 刚超过 +0.005、正向快照比例 68.75%，所以 `summary.json` 机械输出 `continue_bounded_execution_validation`。没有修改参数、阈值或该输出来迎合后续结论。

之后做了明确标为 post-hoc 的样本稳定性复核，未增加环境步、未调整参数：

- 交换选路和独立复核两批样本后，相对静态的场景等权差值为 **−0.000224**，方向没有保持。
- correlated-first 两批样本选中完全相同团队组合仅 **1/16**；静态、到达折扣、时变边际也仅为 2/16、3/16、2/16。说明当前样本量下多种方法都存在组合选择波动，不能只责备某一个评分器。
- 去掉任一场景的均值范围约 **[0.002100, 0.007800]**，6 次中 3 次低于原 0.005 粗筛门槛。

完全相同组合比例低可能同时反映近似并列路线，不能单凭它判定收益无效；但配合复核方向翻转和跨零区间，当前数据没有提供稳定改进证据。机械粗筛通过与审计建议暂缓并不矛盾：前者只作候选筛选，后者考虑已发现的估计不稳定性。

## 模型与计算限制

当前位置 belief 被 lift 为独立各向同性速度先验 U(0.25,0.55)，没有现成的历史条件速度后验。预测使用当前已知占据体素的共享反射函数，未知障碍反射未建模；Searcher 使用现有公开运动学模型，未来流场为零，不预测安全替换/未来地图/高层重规划。因此即便样本量无限，本轮模型内收益也不自动等价于真实环境收益。

本轮完整离线扫描耗时约 140.87 秒；每快照中位数 8.46 秒、最大 14.25 秒，包含候选生成、两组目标样本传播和全部组合比较。这是未优化的诊断批处理成本，不是单次部署规划延迟测量，尚不能声称在线实时可用。

## 去留建议

1. 保留独立诊断代码及当前结果；不要将 BA-STPR 接入生产或论文正式对比主线。
2. 当前最值得继续的窄问题是：在同一快照和候选池上，增加/分层目标样本后能否得到稳定排序和稳定的独立复核收益；同时检查相关路线是否仅近似并列。这一步只需离线计算，不需要训练。
3. 若采样稳定后仍无收益，或收益依赖不可信的速度 lift，应停止固定终点路线改进方向，而非继续增加评分项。若稳定收益出现，再开展用户指定的小型实际执行验证，验证 ETA、跟踪、安全替换及真实发现差异。

本轮没有自动执行这些后续阶段，也没有建立 `performance_passed`。
